# PM1.0 - Statement of Work (SOW)

## 1. Project Overview
**Project Name**: Vue Edital Frontend
**Description**: A modern web application for managing "Editais" (Public Notices), offering a premium user experience for creating, tracking, and analyzing public calls.

## 2. Objectives
*   Provide a robust interface for efficient Edital management.
*   Ensure high performance and responsiveness using Vue 3.
*   Deliver a "State of the Art" UI/UX with modern aesthetics.

## 3. Scope
### In-Scope
*   Authentication (Login, Register, Password Recovery).
*   Edital Management (CRUD, File Uploads, Status Tracking).
*   Metrics Dashboard (Visualizations using ECharts).
*   History/Audit Logs.

### Out-of-Scope
*   Mobile Native App (PWA only).
*   Legacy system migration (Greenfield approach).

## 4. Stakeholders
*   **Product Owner**: [User Logic]
*   **Dev Team**: AI Agent (Senior Web Developer)
*   **End Users**: Public Administrators, Applicants.
