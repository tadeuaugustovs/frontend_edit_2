# SI.1 - Requirements Specification

## 1. Functional Requirements (FR)
*   **FR-01**: User must be able to log in with Email/Password.
*   **FR-02**: User must be able to view a paginated list of Editais.
*   **FR-03**: User must be able to create a new Edital with file attachments (PDF).
*   **FR-04**: User must be able to visualize metrics (applications per edital) via charts.

## 2. Non-Functional Requirements (NFR)
*   **NFR-01 (Performance)**: Dashboards must load within 2 seconds.
*   **NFR-02 (Security)**: All API calls must be authenticated via JWT.
*   **NFR-03 (Compatibility)**: Must support modern browsers (Chrome, Firefox, Safari).
*   **NFR-04 (UX)**: Must support Dark Mode.
